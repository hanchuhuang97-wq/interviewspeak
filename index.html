Setup needed

登录还没配置

这是一个家长 / 老师登录门禁。请先连接 Supabase：

  1. 在 Supabase 创建项目，打开 Authentication → Providers，启用 Email，并关闭 Confirm email（用户名账号不接收真实邮件）。
  2. 在 Project Settings → API 复制 Project URL 和 anon public key。
  3. 打开本项目的 assets/auth-config.js，填入这两个值并刷新；usernameDomain 可以保留默认。
  4. 在 Authentication → URL Configuration 把本站地址加入 Site URL / Redirect URLs。

只想本地预览？把 auth-config.js 的 enabled 改成 false；上线前一定要改回 true。
